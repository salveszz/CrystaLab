# Original data inputs

The current complete synthetic dataset is versioned at
[`artifacts/full_pipeline_20261124_v1/dataset/`](../artifacts/full_pipeline_20261124_v1/dataset/).
Its raw histories, final fields and 1,080 samples remain available for independent
auditing and retraining.

The retained uploaded inputs are:

| File | Purpose |
|---|---|
| `COD.zip` | Original structural-reference archive, read directly by the material tool. |
| `config_kinetic_integration_code.py` | Uploaded integration proposal; unused by the accepted runtime. |
| `kdp_crystal_growth_training_dataset_documentation.md` | Uploaded proposal; not the adopted dataset specification or calibrated kinetics. |

Generated datasets, downloaded source caches and duplicate working copies were
removed during the requested presentation cleanup on 25 November 2026. Source
registries, licenses and acquisition/generation protocols remain in `configs/`,
`SOURCES.md` and `docs/`. Paths in historical reports describe the original
experiments; reacquire or regenerate those inputs before repeating them.

The presentation embeds its selected source frames and scientific figures.
The retained uploaded proposals do not establish a calibrated physical KDP model;
see [physical data](../docs/PHYSICAL_DATA.md) for the accepted interpretation.
